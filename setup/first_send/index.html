    5 分钟发送第一条弹幕

    本教程带你走完从「安装程序」到「成功发送第一条弹幕」的完整流程。完成后，你将掌握工具的核心用法。

    第 1 步：下载与启动

    前往 GitHub Releases 页面，下载最新版本的可执行文件，解压后双击运行。

    程序启动后，你会看到主界面，默认显示「弹幕发射器」页面：

    ┌──────────────┬───────────────────────────────────────┐
│  [用户头像]   │                                       │
│  未登录       │        弹幕发射器 (默认首页)            │
│──────────────│                                       │
│ ▶ 全局设置    │   ┌─────────────────────────────┐     │
│ ▶ 弹幕发射器  │   │      发送队列 (空)           │     │
│ ▶ 弹幕监视器  │   │                             │     │
│ ▶ 弹幕历史记录 │   └─────────────────────────────┘     │
│              │                                       │
│              │   [新建任务]  [启动队列]                │
└──────────────┴───────────────────────────────────────┘

    第 2 步：登录 B 站账号

    程序需要你的 B 站身份凭证才能发送弹幕。

    1. 点击侧边栏顶部的 用户头像区域，打开「账号管理」弹窗。
    2. 按照 登录 B 站账号 教程，从浏览器中复制 SESSDATA 和 bili_jct。
    3. 将两个值分别填入对应输入框，点击 保存。

    验证登录状态

    保存后，侧边栏顶部应显示你的 B 站用户名和头像。如果仍显示「未登录」，请检查凭证是否复制完整（不要多复制空格）。

    第 3 步：准备弹幕文件

    你需要一个 XML 格式的弹幕文件。常见的获取方式：

    来源 说明
    bilibili-evolved 浏览器扩展，可导出视频弹幕为 XML
    弹幕姬 (DanmakuFactory) 本地弹幕处理工具
    其他弹幕采集工具 只要输出 B 站标准 XML 格式即可

    XML 文件的典型结构如下：

    <?xml version="1.0" encoding="UTF-8"?>
<i>
  <d p="12.34,1,25,16777215,1234567890,0,abc123,12345678">这是一条弹幕</d>
  <d p="15.67,1,25,16777215,1234567891,0,def456,12345679">这是另一条弹幕</d>
</i>

    第 4 步：创建发送任务

    1. 在「弹幕发射器」页面，点击 [新建任务] 按钮（或按 Ctrl+N）。

    2. 在弹出的对话框中：

      填写目标视频

      • 在「视频 BV 号」输入框中粘贴视频链接或 BV 号。
      • 支持直接粘贴完整 URL，例如：https://www.bilibili.com/video/BVxxxxxxxxx/?p=3
      • 程序会自动获取视频信息并选中对应的分 P。

      导入弹幕文件

      • 点击 [选择文件] 按钮，选择你准备好的 XML 文件。
      • 也可以直接将 XML 文件 拖放 到发射器页面的队列表格中。

    3. 确认信息无误后，点击 [确定]，任务会出现在发送队列中。

    发送前建议

    强烈建议在发送前先使用「弹幕编辑器」校验一遍弹幕（右键任务 → 编辑弹幕），清理掉换行符、超长内容等问题，避免发送过程中频繁报错。详见 校验规则与异常标红。

    第 5 步：开始发送

    1. 确认队列中已有任务，且状态为「等待中」。
    2. 点击 [启动队列] 按钮（或按 Ctrl+Enter）。

    3. 程序开始自动逐条发送弹幕，进度条实时更新：

      正在发送: 23 / 156 条  ████░░░░░░░░░░░░  14.7%  预计 19:32 结束

    4. 发送过程中你可以：

      • 观察日志面板中的实时输出。
      • 点击 [紧急停止] 随时中断发送。
      • 最小化窗口 —— 程序会缩到系统托盘继续后台运行。

    关于发送速度

    默认配置下，每条弹幕间隔约 8~8.5 秒。这是为了模拟人工操作、避免触发 B 站的频率限制。你可以在「全局设置」中调整延时策略，详见 频率控制与并发策略。

    第 6 步：查看结果

    任务完成后，程序会弹出结果摘要：

    结果类型 含义
    ✅ 成功 弹幕已提交至 B 站服务器，等待审核后显示
    ⏭️ 跳过 该弹幕已在历史记录中（断点续传生效）
    ❌ 失败 发送失败，程序会提示是否导出失败弹幕

    桌面通知

    任务结束时，Windows 任务栏会弹出系统通知，即使窗口已最小化也不会错过。

    如需确认弹幕是否真的显示在视频上，可切换到「弹幕监视器」页面进行存活率验证，详见 实时存活率仪表盘。
