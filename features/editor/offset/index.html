    时间轴平移修正

    当视频存在多个版本（如不同压制源、不同字幕组）时，同一份弹幕 XML 的时间轴可能与目标视频存在整体偏移。时间轴平移功能可以一次性修正所有弹幕的出现时间。

    典型场景

    你有一个视频的弹幕 XML，但目标视频比原始视频 整体快了 2 秒（可能是不同压制源导致的）。此时需要将所有弹幕的时间轴 向后推迟 2 秒。

    操作方式

    方式一：整体平移（所有弹幕）

    1. 点击顶部工具栏 [批量处理] → [整体平移时间轴]。
    2. 在弹出的对话框中输入偏移秒数：
      • 正数（如 2）：所有弹幕时间 向后推迟 2 秒。
      • 负数（如 -1.5）：所有弹幕时间 向前提前 1.5 秒。
      • 支持小数，精度到毫秒。
    3. 点击确认，所有弹幕的时间轴完成整体平移。

    方式二：平移选中的弹幕

    如果你只想平移部分弹幕（例如某个时间段的弹幕偏移量不同）：

    1. 在列表中 选中 一条或多条弹幕（按住 Ctrl 或 Shift 多选）。
    2. 右键 → 选择 「平移选中弹幕的时间轴」。
    3. 输入偏移秒数，确认。

    预览模式下的操作建议

    时间轴平移后，建议切换到 「预览模式（全量显示）」，按时间顺序浏览弹幕，确认偏移量是否正确。

    注意事项

    注意点 说明
    精度 支持小数秒，精度到毫秒（如 1.234）
    可撤销 平移操作会自动入撤销栈，误操作可立即撤销
    负数时间 平移后时间戳为负数的弹幕会被自动修正为 0
    与视频时长的关系 平移后超出视频总时长的弹幕会在下次校验时被标记
