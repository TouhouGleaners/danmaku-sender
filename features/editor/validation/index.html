    校验规则与异常标红

    弹幕编辑器内置了一套校验引擎，能在发送前帮你发现并拦截不符合 B 站规则的弹幕，避免无效发送浪费时间。

    如何触发校验

    在编辑器弹窗中，点击顶部工具栏的 [开始校验] 按钮。程序会自动检查所有弹幕，并将问题弹幕以 淡红背景 + 红字问题描述 高亮显示。

    校验完成后，底部状态栏会显示结果：

    状态 含义
    ❌ 发现 N 条问题弹幕，请处理。 存在需要修复的弹幕
    ✅ 验证通过，当前无问题。 所有弹幕均符合规范

    系统硬性规则（自动生效，无需配置）

    以下规则由程序内置，始终生效：

    1. 长度限制

    弹幕内容 不得超过 100 个字符（B 站 API 硬性限制）。

    • 超过 100 字的弹幕会被标红。
    • 可使用 批量修复工具 中的「一键截断过长弹幕」快速修复。

    2. 换行符检查

    弹幕内容中 不得包含换行符（\n 或 /n）。

    • XML 文件从某些工具导出时，弹幕内容可能意外包含换行符。
    • 可使用 批量修复工具 中的「一键去除所有换行符」批量修复。

    3. 禁用符号

    以下符号在 B 站弹幕中会被系统拦截，包含这些符号的弹幕会被标红：

    ☢ ⚠ ☣ ☠ ⚡ 💣 ⚔ 🔥

    程序会报告命中的第一个禁用符号，例如：包含禁用符号'⚡'。

    4. 时间戳越界

    如果已选择目标分 P（即已知视频时长），出现时间超出视频总时长的弹幕会被标红。

    • 例如视频总长 10 分钟，但某条弹幕的时间戳为 12 分钟。
    • 可使用 时间轴平移修正 整体调整时间轴。

    自定义关键词过滤

    除了系统规则外，你还可以配置自定义关键词列表，拦截包含特定词语的弹幕。

    开启方式

    在编辑器顶部的「校验与过滤规则」区域：

    1. 勾选 关键词拦截 复选框。
    2. 在输入框中填入关键词，使用 中文逗号 或 英文逗号 分隔。
    3. 点击 [开始校验]，包含关键词的弹幕会被标红。

    匹配规则

    • 部分匹配：只要弹幕内容中包含关键词即命中，不需要完全一致。例如输入 广告 会匹配 广告、广告位、小广告 等。
    • 大小写不敏感（针对英文）：关键词匹配前会统一转为小写，例如输入 test 会匹配 TEST、Test、test。
    • 多关键词：一条弹幕可以同时命中多个关键词，问题描述中会列出所有命中的词。

    示例

    输入关键词：广告, 推广, 加群

    校验结果示例：

    问题描述: 命中自定义过滤词: '广告', '加群'
弹幕内容: 欢迎加群123456，这是广告位招租

    安全建议

    补档前请务必开启关键词过滤，检查 XML 中是否混入了广告、引流或敏感内容。这些内容不仅会导致弹幕被 B 站审核拦截，还可能触发账号风控甚至封禁。

    预览模式

    默认情况下，编辑器只显示有问题的弹幕（校验未通过的）。

    勾选顶部的 「预览模式（全量显示）」 复选框后，所有弹幕都会显示：

    显示样式 含义
    灰色文字 正常弹幕，校验通过
    淡红背景 + 红字问题描述 问题弹幕，需要处理

    预览模式适合在修复完问题弹幕后，整体浏览确认无遗漏。

    编辑器工作流建议

    导入 XML → 开始校验 → 修复红行 → (重新校验) → 应用所有修改 → 返回发射器

    操作顺序

    建议先用批量修复工具处理共性问题（换行、超长），再逐条处理个别问题（禁用符号、时间越界），最后重新校验确认全部通过后再应用修改。
