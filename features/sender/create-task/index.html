    任务创建与队列操作

    本页介绍如何在「弹幕发射器」页面创建发送任务、管理队列，以及任务的完整生命周期。

    创建新任务

    点击 [新建任务] 按钮（或按 Ctrl+N），弹出任务创建对话框。

    填写目标视频

    在「视频 BV 号」输入框中，可以输入以下任意格式：

    输入格式 示例
    纯 BV 号 BV1z84C6dEN8
    完整视频链接 https://www.bilibili.com/video/BV1z84C6dEN8/
    带分 P 参数的链接 https://www.bilibili.com/video/BV1z84C6dEN8/?p=8

    程序会自动：

    1. 调用 B 站 API 获取视频信息（标题、封面、分 P 列表）。
    2. 如果链接中带有 ?p=3 参数，自动选中第 3 分 P。
    3. 在分 P 下拉框中展示所有可用分 P 供手动选择。

    操作技巧

    直接从浏览器地址栏复制链接粘贴进来，是最快的输入方式。

    导入弹幕文件

    两种方式将 XML 弹幕文件导入任务：

    方式一：对话框内选择文件

    在任务创建对话框中点击 [选择文件] 按钮，浏览并选择本地的 XML 文件。

    方式二：拖放文件到队列表格

    直接将 XML 文件从文件管理器 拖放 到发射器页面的队列表格中。如果拖放到已有任务的行上，该文件会替换该任务的弹幕内容。

    确认并添加

    填写 BV 号、选择分 P、导入 XML 后，点击 [确定]。任务会以一行记录的形式出现在队列表格中。

    队列表格

    队列表格是发射器页面的核心区域，显示所有已创建的发送任务。

    表格列说明

    列 内容
    序号 任务在队列中的顺序
    视频信息 目标视频的 BV 号和分 P 标识
    弹幕数 该任务包含的弹幕条数
    状态 当前任务状态（见下方状态机）
    操作 右键菜单可用的操作
    进度 发送进度条（仅发送中时显示）

    拖拽排序

    任务行支持 拖拽排序。在发送前，你可以通过拖拽调整任务的执行顺序。

    拖放文件

    将 XML 文件直接拖放到表格行上，可以快速替换该任务的弹幕文件，无需打开编辑对话框。

    任务状态机

    每个任务在其生命周期中会经历以下状态：

      ┌──────────────┐
  │ UNCONFIGURED │  未配置（未导入弹幕）
  └──────┬───────┘
         │ 导入弹幕
         ▼
  ┌──────────┐
  │ PENDING  │  等待中
  └────┬─────┘
       │ 启动队列
       ▼
  ┌──────────┐
  │ RUNNING  │  发送中
  └────┬─────┘
       │
  ┌────┴────┐
  ▼         ▼
┌─────────┐ ┌─────────┐
│COMPLETED│ │ FAILED  │  成功 / 失败
└─────────┘ └─────────┘
    状态 含义 可执行操作
    UNCONFIGURED 未配置弹幕（刚创建但未导入 XML） 导入弹幕、编辑、删除
    PENDING 等待中，弹幕已就绪 编辑、删除、拖拽排序
    RUNNING 正在发送中 停止队列
    COMPLETED 发送完成（全部成功或跳过） 查看结果、移除
    FAILED 发送失败（存在不可重试的错误） 查看错误、导出失败弹幕、移除
    PAUSED 手动暂停 恢复、移除

    UNCONFIGURED 任务的处理

    如果启动队列时存在 UNCONFIGURED 状态的任务（即未导入弹幕），程序会自动将其标记为「跳过」并继续处理下一个任务。

    队列操作

    启动队列

    点击 [启动队列] 按钮（或按 Ctrl+Enter），程序按队列顺序逐任务执行发送。

    启动后：

    • 队列中所有 PENDING 状态的任务将按顺序进入 RUNNING。
    • 表格中的 BV 号、分 P 选择等参数会被 锁定（防止运行中误改）。
    • 进度条开始更新，显示当前任务进度、百分比和 ETA 预测。

    运行期间

    如需修改参数，请先点击 [紧急停止]，修改后重新启动。

    停止队列

    点击 [紧急停止] 按钮，当前任务立即中断，队列中剩余任务不再执行。

    已发送成功的弹幕不会回滚。

    右键菜单

    在队列表格中右键某个任务，可以执行：

    操作 说明
    编辑弹幕 打开弹幕编辑器弹窗
    查看任务详情 查看该任务的完整配置和弹幕统计
    移除任务 从队列中删除该任务（仅 PENDING/COMPLETED/FAILED 状态可删除）

    删除任务

    选中任务后按 Delete 键，或通过右键菜单移除。只有 PENDING、COMPLETED、FAILED 状态的任务可以删除，RUNNING 状态的任务需要先停止队列。

    任务完成后的处理

    任务完成后，程序会弹出结果摘要对话框：

    结果 含义 建议操作
    ✅ 成功 弹幕已提交至 B 站服务器 无需操作
    ⏭️ 跳过 该弹幕已在历史记录中（断点续传生效） 无需操作
    ❌ 失败 发送失败 保存失败弹幕，稍后重新发送

    成功 ≠ 存活

    「发送成功」仅表示 B 站服务器接受了你的弹幕请求，不代表弹幕一定会显示在视频上。B 站的审核系统可能会在后续拦截部分弹幕（尤其是含有特殊符号、敏感词或新账号发送的弹幕）。如需确认弹幕是否真正存活，请使用「弹幕监视器」进行存活率验证。

    失败弹幕导出

    如果存在发送失败的弹幕，程序会弹出对话框询问「是否保存失败弹幕」。选择「是」后，失败的弹幕会导出为新的 XML 文件，方便后续重新发送。

    桌面通知

    任务结束时，Windows 任务栏会弹出系统通知，即使窗口已最小化到托盘也不会错过。
