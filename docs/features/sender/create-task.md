# 任务创建与队列操作

本页介绍如何在「弹幕发射器」页面创建发送任务、管理队列，以及任务的完整生命周期。

---

## 创建新任务

点击 **[新建任务]** 按钮（或按 `Ctrl+N`），弹出任务创建对话框。

### 填写目标视频

在「视频 BV 号」输入框中，可以输入以下任意格式：

| 输入格式 | 示例 |
|:---------|:-----|
| 纯 BV 号 | `BV1z84C6dEN8` |
| 完整视频链接 | `https://www.bilibili.com/video/BV1z84C6dEN8/` |
| 带分 P 参数的链接 | `https://www.bilibili.com/video/BV1z84C6dEN8/?p=8` |

程序会自动：

1. 调用 B 站 API 获取视频信息（标题、封面、分 P 列表）。
2. 如果链接中带有 `?p=3` 参数，自动选中第 3 分 P。
3. 在分 P 下拉框中展示所有可用分 P 供手动选择。

!!! tip "操作技巧"
    直接从浏览器地址栏复制链接粘贴进来，是最快的输入方式。

### 导入弹幕文件

两种方式将 XML 弹幕文件导入任务：

**方式一：对话框内选择文件**

在任务创建对话框中点击 **[选择文件]** 按钮，浏览并选择本地的 XML 文件。

**方式二：拖放文件到队列表格**

直接将 XML 文件从文件管理器 **拖放** 到发射器页面的队列表格中。拖放过程中表格上会浮出提示，说明当前落点会做什么：

- **拖到空白处或表头**（列标题那一行）：每个 XML 文件生成一条新任务。此时还没有指定视频目标，任务处于「未配置」状态，之后在任务详情里补上视频即可。表头的存在是为了应对行数填满可视区、没有空白可落的情况。
- **拖到已有任务的行上**：该文件替换该任务的弹幕内容。多个文件从命中行起按顺序分配给可编辑的任务。
- **拖到不可编辑的行上**（已完成、失败、发送中）：不响应。

### 确认并添加

填写 BV 号、选择分 P、导入 XML 后，点击 **[添加到队列]**。任务会以一行记录的形式出现在队列表格中；追加模式下弹窗保持打开，便于连续新建。

---

## 队列表格

队列表格是发射器页面的核心区域，显示所有已创建的发送任务。

### 表格列说明

| 列 | 内容 |
|:---|:-----|
| 序号 | 任务在队列中的顺序 |
| 视频标题 | 目标视频的标题（未指定目标时显示「未指定视频目标」） |
| 分 P | 目标分 P 编号（未指定目标时显示「—」） |
| 弹幕数 | 该任务包含的弹幕条数 |
| 状态 | 当前任务状态（见下方状态机） |
| 进度 | 发送进度条（各状态均显示，按状态给出文字或百分比） |

### 拖拽排序

任务行支持 **拖拽排序**。在发送前，你可以通过拖拽调整任务的执行顺序。

### 拖放文件

将 XML 文件直接拖放到**表格行**上，可以快速替换该任务的弹幕文件，无需打开编辑对话框；拖放到**空白处或表头**则新建未配置的任务。

## 任务状态机

每个任务在其生命周期中会经历以下状态：

```
  ┌──────────────┐
  │ UNCONFIGURED │  未配置（弹幕或视频目标未就绪）
  └──────┬───────┘
         │ 补齐弹幕与视频目标
         ▼
  ┌──────────┐
  │ PENDING  │  等待中
  └────┬─────┘
       │ 启动队列
       ▼
  ┌──────────┐
  │ RUNNING  │  发送中
  └────┬─────┘
       │
  ┌────┴────┐
  ▼         ▼
┌─────────┐ ┌─────────┐
│COMPLETED│ │ FAILED  │  成功 / 失败
└─────────┘ └─────────┘
```

| 状态 | 含义 | 可执行操作 |
|:-----|:-----|:-----------|
| **UNCONFIGURED** | 配置未完成（缺弹幕、缺视频目标，或两者都缺） | 补配置、编辑、删除 |
| **PENDING** | 等待中，弹幕与视频目标均已就绪 | 编辑、删除、拖拽排序 |
| **RUNNING** | 正在发送中 | 停止队列 |
| **COMPLETED** | 发送完成（全部成功或跳过） | 查看结果、删除 |
| **FAILED** | 发送失败（存在不可重试的错误） | 查看错误、导出失败弹幕、删除 |
| **PAUSED** | 停止队列时被打断的发送中任务 | 删除 |
| **SKIPPED** | 启动时因缺配置被跳过，或因队列中止未轮到 | 补配置、编辑、删除 |

状态列的悬停提示会写清缺什么（「未导入弹幕」「未指定视频目标」，或两者）；任务详情里也有对应的「待补配置」一行。

!!! note "未配置任务的处理"
    如果启动队列时存在 UNCONFIGURED 状态的任务，程序会将其标记为「跳过」并在悬停提示里说明缺什么，然后继续处理下一个任务。补完配置后，任务自动回到「等待中」。

## 队列操作

### 启动队列

点击 **[启动队列]** 按钮（或按 `Ctrl+Enter`），程序按队列顺序逐任务执行发送。

启动后：

- 队列中所有 PENDING 与 PAUSED 状态的任务将按顺序进入 RUNNING。
- 表格中的 BV 号、分 P 选择等参数会被 **锁定**（防止运行中误改）。
- 进度条开始更新，显示当前任务进度、百分比和 ETA 预测。

!!! warning "运行期间"
    如需修改参数，请先点击 **[停止队列]**，修改后重新启动。

### 停止队列

点击 **[停止队列]** 按钮，当前任务立即中断，队列中剩余任务不再执行。

已发送成功的弹幕不会回滚。

### 右键菜单

在队列表格中右键某个任务，可以执行：

| 操作 | 说明 |
|:-----|:-----|
| 查看详情/编辑配置 | 查看该任务的完整配置和弹幕统计（任何状态可用） |
| 编辑弹幕 | 打开弹幕编辑器弹窗（PENDING/UNCONFIGURED/SKIPPED 可用） |
| 上移 / 下移 | 调整任务在队列中的顺序（也可直接拖拽排序） |
| 在上方 / 下方插入任务 | 以当前任务为参照插入新任务 |
| 导出未发送成功 | 导出该任务未发送成功的弹幕 |
| 删除 | 从队列中移除该任务 |

### 删除任务

选中任务后按 ++delete++ 键，或通过右键菜单删除。

!!! warning "删除限制"
    仅**发送中**的任务不可删除，其余状态（已完成、失败、暂停、跳过）均可删除。队列执行期间所有队列维护操作均不可用，需待队列停止后进行。

### 队列维护

工具栏右侧的三个按钮作用于整条队列：

| 按钮 | 作用 |
|:-----|:-----|
| **重置队列** | 移除已完成的任务、把失败的任务转回待发。跳过与未配置的任务保留，待发 / 暂停 / 发送中的任务不动 |
| **清空队列** | 移除队列中的所有任务 |
| **导出未发送** | 把各任务未发送成功的弹幕导出为 XML，每个任务一个文件 |

## 任务完成后的处理

已处理的弹幕有三种结果：

| 结果 | 含义 | 建议操作 |
|:-----|:-----|:---------|
| ✅ 成功 | 弹幕已提交至 B 站服务器 | 无需操作 |
| ⏭️ 跳过 | 该弹幕已在历史记录中，不会重复发送 | 无需操作 |
| ❌ 失败 | 发送失败 | 导出后修正或删除 |

**未轮到发送**的弹幕不计入以上三类，归入「未发送成功」，可导出（见下）。

汇总显示在**日志面板**末尾：

```
--- 发送任务结束 ---
总计: 500 | 成功: 287 | 跳过: 200 | 失败: 13
```

!!! warning "成功 ≠ 存活"
    「发送成功」仅表示 B 站服务器接受了你的弹幕请求，**不代表弹幕一定会显示在视频上**。B 站的审核系统可能会在后续拦截部分弹幕（尤其是含有特殊符号、敏感词或新账号发送的弹幕）。如需确认弹幕是否真正存活，请使用「弹幕监视器」进行存活率验证。

!!! note "未发送成功的弹幕导出"
    任务结束后若存在未发送成功的弹幕（**发送失败**与**未轮到发送**的弹幕；查重跳过的不计入，它们已成功发送），程序会询问是否导出，每个任务生成一个 `{原文件名}_Unsent.xml`。详见 [断点续传与智能去重](resume.md)。

!!! tip "桌面通知"
    任务结束时，Windows 任务栏会弹出系统通知，即使窗口已最小化到托盘也不会错过。
