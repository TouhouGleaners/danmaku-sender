# 批量修复工具

编辑器顶部工具栏的 **[批量处理]** 下拉菜单提供了多种针对整批弹幕的快速修复方案，适合处理 XML 文件中的共性问题。

---

## 一键去除所有换行符

**位置**：批量处理 → 一键去除所有换行符

XML 文件从某些工具导出时，弹幕内容可能意外包含换行符（`\n` 或 `/n`）。这些换行符会导致 B 站 API 拒绝发送。

**操作结果**：

| 情况 | 处理方式 |
|:-----|:---------|
| 内容包含换行符 | 自动去除换行符，保留其余内容 |
| 内容去除换行符后为空 | 自动删除该条弹幕 |

操作完成后会弹出结果摘要：

```
修复: 12 条
删除: 2 条
```

---

## 一键截断过长弹幕

**位置**：批量处理 → 一键截断过长弹幕 (>100字)

B 站弹幕长度上限为 100 个字符。超过此限制的弹幕会被 API 拒绝。

**操作结果**：

- 将超过 100 字的弹幕 **截断至 100 字**（保留前 100 个字符）。
- 不影响长度在 100 字以内的弹幕。

操作完成后会弹出结果摘要：

```
已截断 5 条过长弹幕。
```

---

## 撤销（Undo）

编辑器的每次操作（包括批量修复、单条编辑、删除、插入、时间平移等）都会被记录到撤销栈中。

- 点击顶部工具栏的 **[↩️ 撤销]** 按钮即可回退到上一个状态。
- 支持多次撤销，直到回退到初始加载状态。

!!! tip "安全网"
    如果批量操作的结果不符合预期（例如截断了不该截断的弹幕），可以立即点击撤销恢复。不必担心误操作。

---

## 推荐的批量修复顺序

```
1. 一键去除所有换行符     ← 先处理最常见的问题
2. 一键截断过长弹幕       ← 再处理长度问题
3. 开始校验              ← 最后校验，确认无遗漏
4. 逐条处理剩余个别问题    ← 禁用符号、时间越界等
5. 应用所有修改
```

!!! note "批量修复 vs 校验"
    批量修复工具是主动修复（直接修改数据），而校验是被动检查（只标记问题不修改）。建议先批量修复，再校验确认。
