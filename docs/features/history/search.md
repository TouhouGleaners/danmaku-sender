# 搜索筛选与单条验证

弹幕历史记录页面是一个本地数据库浏览器，查看所有历史发送记录，并支持在线验证单条或批量弹幕的存活状态。

---

## 页面布局

| 区域 | 说明 |
|:-----|:-----|
| **搜索栏** | 输入关键词或 BV 号，按回车搜索 |
| **状态筛选** | 下拉框：全部状态 / 待验证 / 已存活 / 已丢失 |
| **记录表格** | 显示匹配的记录列表 |
| **操作按钮** | 刷新数据、验证全部 |

---

## 搜索与筛选

### 关键词搜索

在搜索框中输入内容后按回车，程序会在本地数据库中搜索匹配的记录。支持搜索：

- 弹幕文本内容
- BV 号

### 状态筛选

下拉框提供四种筛选条件：

| 筛选项 | 说明 |
|:-------|:-----|
| 全部状态 | 显示所有记录 |
| 待验证 | 只显示已发送但尚未在线验证的记录 |
| 已存活 | 只显示已确认在弹幕池中可见的记录 |
| 已丢失 | 只显示已确认丢失的记录 |

搜索和筛选可以组合使用。例如：搜索某个 BV 号 + 筛选「已丢失」状态，快速定位该视频的丢失弹幕。

---

## 记录表格

每条记录包含以下信息：

| 列 | 说明 |
|:---|:-----|
| BV 号 | 目标视频的 BV 号 |
| 分 P | 目标分 P 的页码 |
| 弹幕内容 | 发送的弹幕文本 |
| 状态 | 当前验证状态（待验证 / 已存活 / 已丢失） |
| 发送时间 | 弹幕发送的时间戳 |

### 视频元数据自动补全

表格加载后，程序会自动向 B 站 API 请求每个 BV 号对应的视频元数据（标题、封面等）。获取成功后，表格中会显示视频标题而非纯 BV 号。

---

## 右键菜单

在记录表格中右键某条记录，可以执行以下操作：

| 操作 | 说明 |
|:-----|:-----|
| 🌐 浏览器打开 | 在默认浏览器中打开该视频页面（自动定位到对应分 P） |
| 📋 查看完整详情 | 弹出详情对话框，显示该条弹幕的完整信息（内容、时间、颜色、模式等） |
| 🔍 验证该分 P 所有弹幕 | 向 B 站弹幕池 API 查询该分 P 的所有弹幕，核销存活状态 |
| 复制 BVID | 将 BV 号复制到剪贴板 |
| 复制内容 | 将弹幕文本复制到剪贴板 |

---

## 验证功能

### 单分 P 验证

右键某条记录 → 选择「验证该分 P 所有弹幕」，程序会：

1. 向 B 站弹幕池 API 查询该分 P 当前可见的所有弹幕。
2. 与本地数据库中该分 P 的所有记录进行 `dmid` 比对。
3. 匹配到的标记为「已存活」，未匹配到的标记为「已丢失」。
4. 自动刷新表格显示最新状态。

### 批量验证

点击页面顶部的 **[🔍 验证全部]** 按钮，程序会一次性验证数据库中所有「待验证」状态的记录。

!!! warning "批量验证的耗时"
    批量验证需要逐个分 P 查询 B 站 API，记录较多时可能需要等待一段时间。验证过程中可以正常切换页面，验证完成后表格会自动刷新。

---

## 详情对话框

双击某条记录，或右键选择「查看完整详情」，会弹出详情对话框，显示：

- 弹幕内容、出现时间、模式、字号、颜色
- 目标视频信息（标题、封面、分 P 列表）
- 发送状态和时间戳
