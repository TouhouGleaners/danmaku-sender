# 界面总览与导航

BiliDanmakuSender 采用左侧侧边栏 + 右侧内容区的经典布局。启动后默认显示「弹幕发射器」页面。

---

## 整体布局

```
┌──────────────────┬────────────────────────────────────────────┐
│  [头像] 用户名    │                                            │
│──────────────────│          右侧内容区                          │
│  ▶ 全局设置       │     （根据侧边栏选择切换）                    │
│  ▶ 弹幕发射器     │                                            │
│  ▶ 弹幕监视器     │                                            │
│  ▶ 弹幕历史记录   │                                            │
│                  │                                            │
│                  │                                            │
│                  │                                            │
└──────────────────┴────────────────────────────────────────────┘
```

- **侧边栏顶部**：显示当前登录用户的头像和用户名。点击可打开「账号管理」弹窗。
- **侧边栏列表**：4 个页面入口，点击切换右侧内容。
- **窗口最小化**时会缩到系统托盘，后台任务继续运行。

---

## 四个主要页面

### 1. 弹幕发射器（默认首页）

核心工作台。所有发送操作从这里开始。

| 区域 | 说明 |
|:-----|:-----|
| **队列表格** | 显示所有发送任务，支持拖拽排序、拖放 XML 文件 |
| **操作按钮** | 新建任务、启动/停止队列 |
| **进度条** | 发送过程中显示当前进度、百分比和 ETA 预测 |
| **日志面板** | 实时显示发送过程中的日志输出 |

**常用快捷键**：

| 快捷键 | 功能 |
|:-------|:-----|
| `Ctrl+N` | 新建任务 |
| `Ctrl+Enter` | 启动队列 |
| `Delete` | 删除选中的任务 |

### 2. 弹幕监视器

用于在发送完成后追踪弹幕的存活状态。

| 区域 | 说明 |
|:-----|:-----|
| **队列任务表格** | 显示当前队列中每个任务的发送/存活/丢失统计 |
| **整体统计仪表盘** | 四个大数字卡片：已发送、已存活、待验证、疑似丢失 |
| **轮询间隔** | 控制多久向 B 站弹幕池查询一次（默认 60 秒） |
| **统计基线** | 只统计某个时间点之后的发送记录（默认：本次启动后） |
| **监视日志** | 每轮核销后的汇总日志 |

### 3. 弹幕历史记录

本地数据库浏览器，查看所有历史发送记录。

| 区域 | 说明 |
|:-----|:-----|
| **搜索栏** | 按关键词或 BV 号搜索 |
| **状态筛选** | 下拉筛选：全部 / 待验证 / 已存活 / 已丢失 |
| **记录表格** | 显示每条弹幕的 BV 号、分 P、内容、状态、发送时间 |
| **右键菜单** | 在浏览器中打开视频、查看详情、验证该分 P、复制内容 |

### 4. 全局设置

配置发送策略、监视参数等全局选项。所有设置在窗口关闭时自动保存。

| 设置组 | 主要选项 |
|:-------|:---------|
| **系统设置** | 阻止电脑休眠 |
| **网络设置** | 使用系统代理 |
| **发送延迟** | 随机间隔范围、爆发模式（每 N 条休息 M 秒） |
| **自动终止** | 已发送条数上限、已用时上限（0 为不限制） |
| **断点续传** | 启用/禁用跳过已发送弹幕 |

!!! note "自定义屏蔽关键词在哪里？"
    自定义屏蔽关键词（关键词拦截）的配置位于「弹幕编辑器」弹窗内的校验规则区域，而非全局设置页面。详见 [校验规则与异常标红](../features/editor/validation.md)。

## 账号管理弹窗

点击侧边栏顶部的用户头像区域打开。

| 功能 | 说明 |
|:-----|:-----|
| **添加账号** | 输入 SESSDATA 和 bili_jct，保存到加密存储 |
| **切换账号** | 点击账号列表中的某条记录，激活为当前账号 |
| **检测有效性** | 批量检查所有已保存账号的登录状态 |
| **删除账号** | 移除不再使用的账号凭证 |

账号凭证通过系统密钥环 (keyring) + Fernet 加密存储在本地，详见 [账号与安全](../config/account.md)。

---

## 弹幕编辑器（弹窗）

编辑器不是一个独立的侧边栏页面，而是从发射器页面中打开的弹窗：

- **新建任务时**自动弹出（如果任务中已导入 XML）
- **右键队列任务** → 选择「编辑弹幕」也可打开

编辑器的功能详见 [校验规则与异常标红](../features/editor/validation.md) 及后续章节。
