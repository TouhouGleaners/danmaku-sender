# 彩虹弹幕与高级特效包

编辑器提供了弹幕阵列生成功能，可以快速创建彩虹弹幕等视觉特效。

---

## 彩虹弹幕

彩虹弹幕是指在同一时间点密集发送多条不同颜色的相同文字，形成彩虹色的视觉效果。

### 生成方式

1. 在编辑器列表中选中一条弹幕作为 **参考基准**（时间点和内容会被继承）。
2. 右键 → **高级生成工具** → **生成彩虹弹幕阵列**。
3. 在弹出的对话框中配置参数：
    - **文本**：弹幕内容（默认继承参考弹幕的文本）。
    - **模式**：滚动 / 底端 / 顶端。
    - **数量**：生成多少条弹幕。
    - **颜色策略**：如何分配颜色。
4. 点击确认，生成的弹幕会插入到参考弹幕之后。

### 颜色策略

| 策略 | 说明 |
|:-----|:-----|
| **B 站原味循环** | 按 B 站 14 色画板的顺序循环分配颜色 |
| **HSV 丝滑彩虹** | 使用 HSV 色彩空间生成平滑的彩虹渐变色 |

## 自定义弹幕包

你可以手动创建 XML 文件来制作自定义弹幕包，用于批量导入。

### XML 格式

```xml
<?xml version="1.0" encoding="UTF-8"?>
<i>
  <d p="时间,模式,字号,颜色,时间戳,弹幕池,用户MID哈希,弹幕ID,权重">弹幕内容</d>
</i>
```

### 字段说明

完整 `p` 属性包含 9 个逗号分隔的字段。对于手动制作弹幕包，**只需要关注前 4 个字段 + 内容**，其余留空即可：

| 字段 | 位置 | 必填 | 说明 |
|:-----|:-----|:-----|:-----|
| 时间 | 第 1 个 | ✅ | 弹幕出现时间，单位秒 |
| 模式 | 第 2 个 | ✅ | 1=滚动, 4=底端, 5=顶端 |
| 字号 | 第 3 个 | ✅ | 25=标准, 18=小, 36=大 |
| 颜色 | 第 4 个 | ✅ | 十进制颜色值（如白色 = 16777215） |
| 时间戳 | 第 5 个 | | 发送时间戳，可填 0 |
| 弹幕池 | 第 6 个 | | 弹幕池类型，通常为 0 |
| 用户MID哈希 | 第 7 个 | | 用户标识哈希，可留空 |
| 弹幕ID | 第 8 个 | | 发送后由 B 站分配，可留空 |
| 权重 | 第 9 个 | | 弹幕权重，可留空 |

最小示例（只填必填字段）：

```xml
<d p="12.34,1,25,16777215,,,,,">这是一条弹幕</d>
```

### 颜色值转换

B 站弹幕颜色使用十进制表示。将十六进制 `#RRGGBB` 直接转为十进制即可。例如：

- 白色 `#FFFFFF` → `16777215`
- 红色 `#FE0302` → `16646914`

完整的 B 站 14 色标准色板及其十进制值，见 [单条编辑与属性检查器](../features/editor/inspector.md#b-站标准色板)。

---

## 批量制作技巧

1. 用 Excel 或文本编辑器批量生成弹幕行。
2. 使用公式转换颜色值。
3. 保存为 `.xml` 文件。
4. 在编辑器中导入，校验后应用到发送任务。
